# 📊 DCF 智能估值面板

输入股票代码 → 自动抓取财务数据 → **DCF / DDM / 反向DCF / 可比公司** 四种方法交叉估值 → 综合研判。

支持 **A股** 和 **美股**，无需任何 API Key 即可使用（财务数据来自公开免费数据源）。

---

## ✨ 功能特性

| 特性 | 说明 |
|---|---|
| 🎯 一键估值 | 输入股票代码或名称（A股如 `600519`/`贵州茅台`，美股如 `AAPL`/`Apple`），自动完成全流程 |
| 🏷️ 估值风格 | 按公司属性（**成长/稳健/价值/周期股**，可自动识别或手动指定）套用对应增长率、永续增长与风险溢价参数 |
| 🎯 推荐合理估值 | 综合研判页汇总各方法中位数，给出**推荐合理估值 + 合理区间 + 对应合理市值**与综合结论 |
| 💰 四种估值方法 | DCF（FCFF 两阶段）、DDM 股利贴现、反向 DCF、可比公司法 |
| 📖 方法论讲解 | 每个方法都内置公式、原理、用法、适用场景与局限说明 |
| ⚙️ 假设可调 | 所有预测假设（增长率、WACC、利润率等）自动生成 + 可手动调整 |

| 🤖 AI 综合研判 | 可选接入大模型（OpenAI/DeepSeek/豆包/通义/Kimi），无 Key 时用本地规则引擎兜底 |

```bash

# macOS/Linux:
source .venv/bin/activate

# 2. 安装依赖
pip install -r requirements.txt
```

## 📖 估值方法速览

- **DCF**：`FCFF = EBIT×(1−t) + 折旧摊销 − 资本开支 − Δ营运资本`，两阶段折现，适用于现金流稳定的公司
- **DDM**：未来股利现值之和，适用于稳定分红公司（银行/公用事业/消费龙头）
- **反向 DCF**：反推当前股价隐含的增长率，与历史对比揭示预期差
- **可比公司**：同业中位 PE/PB/EV-EBITDA 套用，相对估值交叉验证

## 🧠 模型校准系统（历史回测自主学习）

为了让估值贴合实际市场表现，系统内置一个**基于历史回测的分层校准**模块，分四个阶段工作：

### 阶段1 — 历史回测引擎
对每只样本股，回到历史时点 t（如 2019 年末），**只用当时可得的数据**（t-1 年报、当时股价、历史 Beta、当时无风险利率）跑完整估值流程，得到"历史合理估值"；再追踪 t 之后 1/2 年的实际股价表现。

- **误差 = 模型隐含预期收益 − 实际超额收益**（超额=相对同期沪深300/标普500，剥离市场 Beta）
- 防前视：财务截断到 t-1 年报、Beta 用截至 t 的前 1 年日线、利率取历史时点值

### 阶段2 — 偏差分层校准
按 **估值风格 × 市场** 分层统计历史误差，生成校准系数：
- 误差 > 0（模型系统性高估）→ 系数 < 1 下调；误差 < 0（系统性低估）→ 系数 > 1 上调
- **失真样本过滤**：DCF 报错 / 隐含收益 >300%（金融地产 FCFF 失真）/ DCF 与 DDM 分歧 >2 倍 的样本剔除，避免污染
- **样本收缩**：样本 <8 时系数向 1.0 收缩，防止小样本过拟合

### 阶段3 — 滚动自学习
- **时间衰减加权**：近期样本权重更高（`w = e^(−0.2×距今) `），更快反映市场结构变化
- **样本持久化 + 断点续跑**：回测样本存本地，数据源恢复后增量扩充，不重复拉数据
- 每季度/定期运行批量回测（A股池：市值≥500 亿；美股池：市值≥1000 亿美元）即可滚动更新

### 阶段4 — 面板交付
综合研判页新增「模型校准状态」区：
- 展示当前 风格×市场 的校准系数、回测样本数、方向命中率、历史均值误差、校准表更新时间
- **开关**控制是否对 DCF/DDM 内在价值应用校准系数（默认开启）
- 校准开启时，方法对比表与推荐合理估值会标注「（已校准）」

> 校准系数是统计性修正，随样本积累与市场变化自动更新；样本不足时自动保守（系数≈1）。

### 运行批量回测（可选，本地）
```bash
# A股校准（市值≥500亿池）
.venv\Scripts\python.exe -m src.calibration.runner A
# 美股校准（市值≥1000亿美元池）
.venv\Scripts\python.exe -m src.calibration.runner US
```
产物：`data/calibration.json`（校准系数表）+ `data/cache/`（行情/财务/样本缓存）。
